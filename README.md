# 城市潜像 / City Afterimage

一个可离线运行的个人城市意象生成器。用户选择城市、回答 8 个递进问题，系统从自然语言中提取空间、感官、文化、关系、情绪与个人叙事，生成一张私人城市认知拓扑图、一句城市宣言和可分享的 PNG。

> 核心不是总结“这座城市有什么”，而是显影“什么让这座城市成为你心里的这座城市”。

## 现在就运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端中显示的本地地址，通常是 `http://localhost:3000`。

比赛现场建议直接点击首页的「直接体验示例」，约 2 秒即可看到完整武汉示例。也可以点击「开始显影」演示逐题交互。

## Demo 已实现

- 武汉、北京、上海、成都、广州 5 个城市入口
- 8 个递进问题：第一帧、路径、身体记忆、地方密码、社会关系、时间、反事实、个人故事
- 零 API 的本地规则分析：关键词、本地语汇、具体性信号、第一人称与感官线索
- 重要度、个人独特性、城市区分度三项评分
- 7 个高权重意象节点与认知拓扑布局
- 自动生成城市宣言、个人叙事路径与潜像注脚
- 所有主要节点可追溯到用户原始回答
- 系统分享或下载 1200 × 1500 PNG
- 桌面端与手机端响应式界面
- 低动态偏好、键盘焦点、语义标签等基础无障碍支持

## 本地生成逻辑

当前版本不把回答发送到服务器，生成过程完全在浏览器中进行。

每条回答会被转换为如下结构：

```ts
{
  label: "江风与暴雨",
  category: "sensory",
  importance: 91,
  uniqueness: 88,
  quote: "用户回答的原始证据",
  x: 30,
  y: 24
}
```

评分主要使用：

1. 回答长度与信息密度；
2. 时间、地点、人物、动作等具体性线索；
3. 第一人称经历与身体感受；
4. 城市在地词命中；
5. “很美、节奏快、烟火气”等泛化表达惩罚；
6. 反事实问题的核心权重。

这不是学术测量量表，分数用于 Demo 内的信息筛选和视觉层级。

## 接入 LLM

`lib/llm-provider.ts` 已定义与本地引擎相同的数据契约。接入时：

1. 新建服务端 `POST /api/analyze`；
2. 将城市和 8 条回答发送给模型；
3. 要求模型只返回 `AnalysisResult` JSON；
4. 服务端校验每个节点的 `quote` 是否能回溯到回答；
5. 请求失败时回退到 `analyzeCityImprint()`。

密钥只能存放在服务端环境变量中，不要以 `NEXT_PUBLIC_` 前缀暴露。

推荐让 LLM 负责语义提取、同义合并与宣言润色，让本地规则继续负责保底、评分归一化和视觉布局。

## 隐私说明

当前 Demo 不上传、不保存回答。刷新页面后数据消失。后续若增加历史地图或多人对比，需要单独设计知情同意、删除机制和匿名化策略。
